# .github

Organization-wide files for [BenchCommons](https://github.com/BenchCommons):

- `profile/README.md`: the public organization profile.
- Default community health files: `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, issue templates and the PR template. They apply to every repo that does not have its own.
- `AGENTS.md`: rules for AI agents working in any BenchCommons repo.

Org decisions and the roadmap live in [.product](https://github.com/BenchCommons/.product).
